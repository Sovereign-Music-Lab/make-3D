# 5. 완성 점검

“import 성공”이나 도구가 오류 없이 끝난 것은 완성이 아닙니다. 아래를 **각각 따로** 확인합니다.

## 캡처로 비교

```bash
python3 scripts/ue_capture.py --out shots --tag before --target 0 0 --height-cm 170
python3 scripts/ue_capture.py --out shots --tag after  --target 0 0 --height-cm 170
```

같은 카메라·조명에서 전후를 나란히 보세요. 움직임은 `--simulate 2`.

## 체크리스트

| 항목 | 확인 방법 | 비고 |
|---|---|---|
| 정면·3/4·측면·후면 외형 | 4방향 캡처 | 뒷모습은 사진에 없으니 특히 확인 |
| 저장 후 재로드 | 다른 레벨 열었다가 다시 열기 → 재질·애니 유지 | |
| 크기·바닥 | 발이 바닥에 닿는지, 키가 맞는지 | `get_actor_bounds` |
| 애니메이션 | Simulate 두 순간 캡처가 다른지 | 에디터 정지 화면은 첫 포즈 |
| 재질 | 피부·옷·머리 반사가 조명에서 자연스러운지 | |
| 관절 변형 | 팔 들기·앉기 포즈에서 어깨·팔꿈치·치마 뚫림 | 모캡 전에 |
| 성능 | 삼각형 수, 텍스처 크기 | 영상용이면 여유, 실시간이면 LOD |

## 조명 기본값(초상용 예)

- 키 라이트(사각 소프트박스) 앞 45°, 필 라이트 약하게, 림 라이트 뒤쪽
- Post Process Volume에서 노출 고정(자동 노출 끄기) → 전후 비교가 공정해짐
